# Tech Stack Manual

## 1. System Overview

The Learning Platform is an education management system, that allows instructors to track student progress, create courses, manage cohorts, and facilitate collaborative learning through integrated GitHub and Slack functionality.
Backend: Django REST API
Frontend: React

### The Learning Platform:

#### Instructor View

- Students: Instructor can view all students, filtered by cohort. Students are organized based on what exercise they are currently working on. Instructors can add Learner Notes, Tag Learner, and Assign to Project.
- Teams: Teams is a tool for the instructor to create teams based on the cohort selected in the Students tab. Instructors can select the teams or use the tool to create the teams
- Cohorts: Instructor can view each cohort, access the github orgs and attendance, join a cohort, invite students, view class calendar.
- Courses: Provides a list of the courses offered and the books within each course.
- Foundations: contains the foundation exercises, allowing the instructor to search by students name and entry dates.

#### Student View

- Overview: Students can view the Cohort timeline, list of github repositories, upcoming events, student information (slack, and current project), Capstone submissions, Self-assessments, and assessment status.
- Capstone: Contains the requirements for the client side and server side capstone projects
- Core Skills: Contains the skill goals students will be achieving through the bootcamp.
- Calendar: contains all events occurring during the bootcamp including group projects, career development, intersession, and holidays.
